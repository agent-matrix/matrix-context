# Measured findings — the routing win is real

This file records the **measured** outcome of the bake-off and eval harness when
a real embedder drives the router, as opposed to the offline hashing stub. It is
the evidence that retires the project's central risk (see `WHITEPAPER.md`).

Date of run: 2026-06-04 · single-node, local · embedder: `sentence-transformers`
(`all-MiniLM-L6-v2`, 384-dim) · store: `memory` · budget: 90 tokens.

> Note: `experiments/results/summary.md` and `results.json` are regenerated by
> the **offline** bake-off on every CI push, so the real-embedder run is
> preserved here and in `bakeoff_sentence-transformers.md` /
> `results_sentence-transformers.json` / `eval_live_router_sentence-transformers.txt`.

## Bake-off (`python -m experiments.runner --embedder st --store memory`)

| algorithm  | recall | distractors | tokens |
|------------|:------:|:-----------:|:------:|
| simple_rag |  100%  |     42      |  603   |
| bm25_rag   |  100%  |     42      |  617   |
| hybrid_rag |  100%  |     41      |  608   |
| **moc_rag** | **100%** | **38**   | **563** |

**Winner: `moc_rag`.** At equal (100%) recall it carries the fewest distractors
(38 vs 42, **−10%**) and the fewest tokens (563 vs 603, **−7%**). With the
offline hashing stub `moc_rag` could not discriminate (79% recall, `simple_rag`
won); swapping in a real embedder flips the result exactly as predicted.

## Eval harness, live router (`python -m eval.harness --embedder st`)

| metric                  | offline STUB | **live router** | CMPT oracle | FLAT |
|-------------------------|:------------:|:---------------:|:-----------:|:----:|
| mean gold recall        |     79%      |    **100%**     |    100%     | 100% |
| total distractors       |     39       |    **38**       |     16      |  42  |
| routing accuracy        |    6/7       |    **7/7**      |      —      |  —   |

With a real embedder the **live router** reaches the oracle's recall (100%) and
perfect routing (7/7), while beating flat RAG on distractors. The simulated
competent-gate (CMPT) remains the ceiling on distractors (16) because it routes
to a single known-correct expert; the live router fans out to `top_experts=2`.

## Promoted winning configuration

- **Embedder (recommended for production):** `sentence-transformers`
  (`all-MiniLM-L6-v2`). The packaged default stays `hashing` so the library is
  dependency-light and offline-by-default; select the real embedder via
  `ContextManager.from_env` with `MATRIX_CONTEXT_EMBEDDER=sentence-transformers`
  or construct `SentenceTransformerEmbedder` directly.
- **Algorithm:** `moc_rag` (the full engine: route → hybrid fuse → budgeted pack).
- **Expert fan-out:** `top_experts=2` — **promoted into the engine defaults**
  (`ContextManager.DEFAULT_TOP_EXPERTS`, `Config.top_experts`, CLI `--top-experts`).
- **Budget:** 90 tokens for the eval/bake-off fixtures; adapters default to a
  low-hundreds per-turn budget (HomePilot 220).

## Honest caveat

The dataset in `experiments/datasets/` is a small synthetic typed set — enough to
exercise the mechanism and tooling, not to support a strong general claim. The
highest-value follow-up is to grow it toward a real long-horizon memory set (the
HomePilot adapter is the path to live gold signal). The Ollama answer-quality
column (`--generator ollama`) was not run in this environment (no local Ollama);
the retrieval-quality result above stands on recall/distractors/tokens.
